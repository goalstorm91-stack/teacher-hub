Firebase 연결이 아직 안 됐어요

일기장은 구글 로그인과 Firebase(구글의 데이터베이스)에 일기를 저장해요. 처음 한 번만 설정하면 돼요. 자세한 순서는 저장소의 README → 일기장 설정하기에 있어요.

  1. Firebase 콘솔에서 프로젝트를 만들고 웹 앱을 추가해요.
  2. Authentication에서 Google 로그인을 켜요.
  3. Firestore Database를 만들고, 저장소의 firestore.rules 내용을 규칙에 붙여 넣어요.
  4. 웹 앱 설정값을 apps/diary/firebase-config.js에 붙여 넣어요.
