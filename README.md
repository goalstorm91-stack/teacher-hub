# 교사 업무효율화 허브

선생님 업무를 돕는 작은 웹앱들을 모아 두는 허브예요. 서버 없이 `index.html`을 더블클릭하면 바로 열립니다.

## 폴더 구조

```
teacher-hub/
├─ index.html          ← 허브 첫 화면 (앱 카드 목록)
├─ apps.js             ← 앱 목록. 새 앱은 여기에 한 덩어리 추가
├─ assets/style.css    ← 모든 앱이 함께 쓰는 디자인 (색, 카드, 버튼)
└─ apps/
   ├─ info-helper/     ← 첫 번째 앱: 정보 담당 도우미
   │  ├─ index.html
   │  └─ app.js
   └─ diary/           ← 두 번째 앱: 일기장 (내 컴퓨터 서버 + DB)
      ├─ 일기장 시작.bat ← 더블클릭하면 서버가 켜져요 (Windows)
      ├─ server.py     ← 일기 저장 서버 (파이썬, 추가 설치 없음)
      ├─ index.html, app.js
      └─ data/diary.db ← 일기가 저장되는 파일 (GitHub에 올라가지 않음)
```

## 새 앱 추가하는 법 (3단계)

1. `apps/` 안에 새 폴더를 만들어요. 예: `apps/seat-maker/`
2. 그 안에 `index.html`을 만들고, `<head>`에 공통 디자인을 연결해요.
   ```html
   <link rel="stylesheet" href="../../assets/style.css" />
   ```
3. `apps.js`의 목록에 카드 정보를 추가해요.
   ```js
   {
     id: "seat-maker",
     name: "자리 배치 도우미",
     desc: "학급 자리를 무작위로 배치해요.",
     icon: "🪑",
     path: "apps/seat-maker/index.html",
     category: "학급 운영",
     status: "ready",
     color: "blue",
   },
   ```

AI에게 새 앱을 부탁할 때는 이렇게 말하면 편해요:
> "teacher-hub 구조에 맞춰 `apps/새앱이름/`에 앱을 만들고, `assets/style.css`의 클래스(card, btn, badge, input, table)를 써 줘. 데이터는 localStorage에 `teacherHub.새앱이름.v1` 키로 저장해 줘."

## 데이터 저장에 대해

- 이 허브는 **선생님 컴퓨터 한 대에서 혼자 쓰는 용도**로 만들었어요.
- 모든 데이터는 **지금 쓰는 브라우저**에만 저장돼요 (localStorage). 다른 컴퓨터나 다른 브라우저에서는 보이지 않아요.
- 브라우저 기록·사이트 데이터를 지우면 사라질 수 있으니, 정보 담당 도우미의 **백업·설정** 탭에서 가끔 백업 파일을 받아 두세요. 2주 넘게 백업하지 않으면 대시보드에 알림이 떠요.
- 비밀번호, 학생 개인정보(주민번호, 연락처 등)는 저장하지 마세요.

## 디자인

Google Stitch 프로젝트의 "Viridian Flow" 스타일(밝은 회청색 배경, 둥근 흰 카드, 딥 그린·일렉트릭 블루 포인트, 알약 모양 버튼)을 참고했어요. 색을 바꾸려면 `assets/style.css` 맨 위 `:root`의 색 값만 고치면 모든 앱에 한 번에 적용돼요.

## 일기장 사용법 (Windows)

일기장은 다른 앱과 달리 **내 컴퓨터에서 작은 서버를 켜야** 써요. 일기가 인터넷으로 나가지 않게 하려고 이렇게 만들었어요.

1. 이 저장소를 컴퓨터에 내려받아요 (GitHub의 `Code → Download ZIP` 후 압축 풀기).
2. `apps\diary\일기장 시작.bat`을 더블클릭해요.
   - 파이썬이 없으면 자동 설치를 물어봐요. `Y`를 누르고, 설치가 끝나면 한 번 더 더블클릭하세요.
3. 검은 창이 뜨고 브라우저에 일기장(`http://localhost:8765`)이 열려요. **검은 창은 일기 쓰는 동안 닫지 마세요.**

- 일기는 `apps\diary\data\diary.db` 파일 하나에 저장돼요. 이 파일만 복사해 두면 백업 끝이에요. 화면의 **백업 받기** 버튼으로 JSON 파일을 받아도 돼요.
- `.gitignore`에 `apps/diary/data/`가 들어 있어서 일기 파일은 GitHub에 올라가지 않아요.
- GitHub Pages 허브에서 일기장 카드를 눌러도 쓸 수 있어요. 이때도 서버가 켜져 있어야 하고, 크롬이 "로컬 네트워크 접근"을 물으면 **허용**을 눌러 주세요. 화면만 인터넷에서 오고, 일기 내용은 내 컴퓨터 서버로만 오가요.
- 서버는 `127.0.0.1`(이 컴퓨터)에서만 접속을 받아서 같은 와이파이의 다른 사람도 들어올 수 없어요.
